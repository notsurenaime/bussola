Features

Built to be read at a glance

Every widget is designed first, wired second. Here is what ships in the MVP.

Dashboard canvas

A drag-and-resize grid built on react-grid-layout. Add a widget, drop it anywhere, and the layout saves itself.

  • Multiple saved layouts per account
  • 8 widgets per dashboard on Solo, ~12 on Team
  • Light and dark, with the Bussola palette

Connections management

Add a source, paste its API key, and Bussola runs a real request before saving. Secrets are encrypted at rest with AES-256-GCM.

  • Per-user credentials, never shared across tenants
  • Connection test on add — no silent failures later
  • Qonto accepts login:secret in one field

Demo data mode

New accounts open on a fully populated dashboard, not an empty grid. Great for evaluating before you connect anything real.

  • Realistic figures across every widget type
  • One switch back to your live connections

Sharing & alerts

Send a read-only link to anyone. Get an email when something needs you — a failed deploy, a cash balance under your threshold.

  • Read-only dashboard links
  • Email alerts on every plan
  • Slack & Discord webhooks on Team

MCP server

Point an agent at Bussola. It can read data from every connector and manage your dashboards, widgets and connection toggles.

  • Read access across all connectors
  • Write access to Bussola's own resources only
  • API keys are never editable over MCP — web UI only
  • Team-wide MCP config on the Team plan
