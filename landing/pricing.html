FAQ

Good to know

Is the hosted version the same code as open source?

Yes. The hosted version is the same app with billing, plan limits and multi-tenant auth on top. Self-hosting removes the limits.

Do connectors cost extra?

No. Every connector is included on every paid plan and on the self-hosted build. You only pay for your own upstream API usage, if any.

What happens to my API keys?

They are encrypted with AES-256-GCM at rest and are only ever editable through the web UI — never through the MCP server or any API.

Can I switch plans or cancel any time?

Yes. Billing runs through Stripe Checkout and the Stripe customer portal, so upgrades, downgrades and cancellation are self-serve.

Is there a free trial?

Every account opens in demo-data mode, so you can explore a full dashboard before connecting anything or entering a card.
