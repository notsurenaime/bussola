FAQ

Before you decide

Is there a free trial?

Better: a free tier. Every account starts on the Trial plan with no card and no countdown — one dashboard, four widgets, every connector. And before you connect anything, widgets render labelled sample data, so you can judge the product with zero setup.

Is the hosted version the same code as the open-source one?

Yes, one codebase. An edition flag decides whether billing, open signup and plan limits are active. Self-hosted never constructs a billing client and never creates a subscription row — the billing code is inert, not merely unused.

Do connectors cost extra?

No, and they never will. Every connector is included on every plan, including the free Trial and the self-hosted build. You only pay for your own upstream API usage, if your providers charge for it.

What happens to my API keys?

They are encrypted with AES-256-GCM at rest and are only ever editable through the web UI — never through the MCP server or an API. Connectors use them for reads only.

Can I switch plans or cancel any time?

Yes. Billing runs through Stripe Checkout and the Stripe customer portal, so upgrades, downgrades, card changes and cancellation are all self-serve.

What does “12 months of history” actually mean?

The worker appends one sample per connection per hour, and retention is pruned against your plan. So the number describes the data you can actually plot, not an aspiration. Self-hosted keeps everything.

What happens if I downgrade?

Nothing is deleted. Limits are enforced only when you create something new, so an over-limit account keeps every dashboard and widget it already has — it just cannot add more until it is back under the limit.

Can I move from hosted to self-hosted later?

That is the point of shipping both. It is the same schema and the same application; self-hosting means pointing it at your own Postgres and dropping every limit.
