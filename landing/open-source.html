Open source

Self-hosting is the trust anchor

The whole app is on GitHub. The hosted version is a convenience, not a lock-in — run Bussola on your own box and you lose nothing.

View the repo Quick start

Local-first

Data lives in ./data/bussola.db (or BUSSOLA_DATA_DIR). Nothing leaves your machine unless you host it.

Encrypted secrets

API keys are sealed with AES-256-GCM at rest. Single-user password auth over an HTTP-only session cookie.

Migratable

Designed to move storage to Postgres with row-level security for cloud and multi-user later, without a rewrite.

Quick start

Running in a few commands

Node and pnpm, then three steps. Open localhost:3000 and set a local admin password.

# install & configure
pnpm install
cp .env.example .env.local
# recommended: set an encryption key
openssl rand -hex 32   # → BUSSOLA_ENCRYPTION_KEY

# migrate & run
pnpm db:migrate
pnpm dev

MCP server

Give an agent a safe seat

Bussola ships an MCP server so an assistant can work with your data and your dashboards — within clear limits.

Can do

  • Read data from every connector
  • Create and delete dashboards
  • Add, remove and move widgets
  • Enable or disable a connection

Cannot do

  • Edit connection credentials — web UI only
  • Write to third-party systems (restart a service, move money)
  • Bypass plan limits or auth

Write actions on third-party systems are deliberately out of scope for the MVP — that needs its own confirmation and audit design.
