Why Bussola

One cockpit for infra and finances

You check deploys and errors to know things are up. You check MRR, cash and open invoices to know where you stand. Today that lives in five to eight separate dashboards. Bussola is the only one built to combine infra + revenue + cash for solo and small-team SaaS operators.

Not a homelab board

Homarr, Dashy and Heimdall track Docker containers — not business numbers.

Not a heavyweight BI tool

Databox, Klipfolio and Grafana start at $49–159/mo and need setup work.

Not single-purpose

Analytics tools show traffic only. Monitoring tools show infra only.

What you get

Everything in one canvas

Dashboard canvas

Drag, resize and add widgets. Keep multiple saved layouts per account for different views of the business.

Connections management

API keys and OAuth per user, AES-256-GCM encrypted, with a live connection test the moment you add one.

Demo data mode

Explore a fully populated dashboard before connecting anything — no empty widget states.

Per-tenant caching

Widgets refresh on a 45–60s interval, keeping upstream API usage and local resource cost low.

Sharing & alerts

Read-only dashboard links. Email alerts on failed deploys or low cash. Slack & Discord on Team.

MCP server

Read every connector's data and manage your own dashboards from an agent. Credentials stay web-UI only.
